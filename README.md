# 🤖 AI Meeting Transcript Reader

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg?style=for-the-badge&logo=python&logoColor=white)](https://www.python.org)
[![Django](https://img.shields.io/badge/Django-Latest-092E20.svg?style=for-the-badge&logo=django&logoColor=white)](https://www.djangoproject.com)
[![Mistral AI](https://img.shields.io/badge/Mistral_AI-Powered-FF7000.svg?style=for-the-badge)](https://mistral.ai/)

> This repository contains a web-based AI assistant designed to analyze, extract, and comprehend information from meeting transcripts. Users can upload a document (`.pdf` or `.txt`) and ask questions, receiving answers generated by a sophisticated RAG (Retrieval-Augmented Generation) pipeline powered by Mistral AI. The application is built with Django and features a sleek, dynamic single-page interface created with vanilla JavaScript.

---

## ✨ Features

*   **Document Q&A:** Upload and interact with your meeting transcripts in `.pdf` and `.txt` formats.
*   **RAG Pipeline:** Utilizes Mistral embeddings and large language models via LangChain for accurate, context-aware answers based on the document's content.
*   **Contextual Guardrails:** The AI is specifically prompted to answer questions based only on the provided document, politely decline to answer out-of-context questions, and clearly state when the requested information is not available.
*   **Chat History:** The model considers the last few turns of the conversation for better follow-up answers.
*   **Modern UI:** A clean, responsive single-page application that transitions from an initial upload screen to a full chat interface.
*   **Session-Based Storage:** The uploaded document and chat history are stored in the server's memory only for the duration of the user's session and are cleared upon closing the page.
*   **Export Chat:** Users can download their entire conversation as a `.txt` file at any time.

---

## ⚙️ How It Works

1.  **File Processing & Chunking:** When a user uploads a document, the backend parses it and splits the text into smaller, overlapping chunks.
2.  **Vector Embedding:** Each text chunk is converted into a numerical vector representation (an embedding) using the `mistral-embed` model. These vectors capture the semantic meaning of the text.
3.  **In-Memory Vector Store:** The text chunks and their corresponding vectors are stored in memory for the current user session, creating a temporary, searchable knowledge base.
4.  **Question Retrieval:** When a user asks a question, it is also converted into a vector. The system then uses cosine similarity to compare this question vector against all chunk vectors in the store, retrieving the chunks that are most semantically similar to the question.
5.  **Answer Generation:** The retrieved chunks (the "context") are passed to a Mistral chat model along with the original question and the recent chat history. This context allows the model to generate a factual and relevant answer based on the document's content.

## 🚀 Local Setup and Installation

Follow these steps to run the project locally on your machine:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/SnehaMs325/BCTproject2.git
    cd BCTproject2
    ```

2.  **Create and activate a virtual environment:**
    ```bash
    # For Windows
    python -m venv venv
    .\venv\Scripts\activate

    # For macOS/Linux
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Set up environment variables:**
    Create a file named `.env` in the root directory of the project and add your Mistral API key:
    ```env
    MISTRAL_API_KEY="your-mistral-api-key"
    ```

5.  **Run Django migrations:**
    ```bash
    python manage.py migrate
    ```

6.  **Start the development server:**
    ```bash
    python manage.py runserver
    ```

The application will be available at `http://127.0.0.1:8000/`.

## 💡 Usage

1.  Open your web browser and navigate to the application's URL.
2.  On the home screen, click the **+** button to open the file selector.
3.  Choose a `.pdf` or `.txt` meeting transcript from your local machine. The selected filename will appear on the screen.
4.  Type your first question about the document into the input bar.
5.  Click the **Get Started** button. The system will upload the file, process it, and answer your question.
6.  The interface will transition to a chat view, where you can ask continuous follow-up questions.
7.  Use the navigation buttons at the top to return to the home screen (which clears the session) or to download the chat transcript.
